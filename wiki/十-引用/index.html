10 引用

作用：给变量起别名。引用是 C++ 相对 C 扩充的一个重要知识点，在函数参数和返回值中都会大量用到。

使用引用时有两点必须注意：

  • 引用必须初始化

10.5 引用的本质

本质：引用的本质在 C++ 内部实现上是一个指针常量。

C++ 编译器在编译过程中，自动帮我们做了转换：

  • int& ref = a; 编译器转换为 int* const ref = &a;
  • 给引用赋值 ref = 20; 编译器转换为 *ref = 20;

指针常量的特点是指针的指向不可以修改，这也再次印证了引用一旦初始化就不可更改。

作用：常量引用主要用来修饰形参，防止误操作。

在函数形参列表中，可以加 const 修饰形参，防止形参改变实参。

  • 引用的本质就是指针的封装，底层就是指针常量
  • 常量引用既可以让形参更安全，又避免了值传递的拷贝开销
  • 当函数的参数是引用且不需要修改实参时，加上 const 是好的习惯
