九.内存分区模型

9 内存分区模型

作用：C++ 程序在执行时，将内存大方向划分为 4 个区域，分别是：代码区、全局区、栈区、堆区。==不同区域存放的数据，赋予不同的生命周期==，给我们带来更大的灵活编程空间。

  • 代码区：存放函数体的二进制代码，由操作系统进行管理
  • 全局区：存放全局变量、静态变量以及常量
  • 栈区：由编译器自动分配释放，存放函数的参数值、局部变量等
  • 堆区：由程序员分配和释放，若程序员不释放，程序结束时由操作系统回收

提示：内存分区模型是 C++ 核心编程的地基，后面学习的引用、类和对象等内容，都建立在对内存四区的理解之上，请务必把这一章学扎实。

9.1 程序运行流程

作用：弄清楚程序从源代码到运行，各阶段分别使用了哪些内存区域，是学习内存分区模型的第一步。一个 C++ 程序从编写到运行，大致经过下面的流程：

  • 编写源代码，保存为 .cpp 源文件；
  • 编译器将源代码翻译成机器指令，链接器把目标文件和用到的库链接成可执行程序；
  • 运行可执行程序前：操作系统把程序加载进内存，划分出代码区和全局区；
  • 运行可执行程序后：程序开始执行，又划分出栈区和堆区。

作用：四个区域各司其职，存放的数据和由谁管理都不相同：

  • 代码区：存放 CPU 执行的机器指令，由操作系统进行管理；
  • 全局区：存放全局变量、静态变量、常量，数据在程序结束后由操作系统释放；
  • 栈区：由编译器自动分配释放，存放函数的参数值、局部变量等；
  • 堆区：由程序员分配和释放，若程序员不释放，程序结束时由操作系统回收。

9.2 内存四区

作用：把数据放进合适的区域，本质上是在为数据选择合适的生命周期。下面逐个介绍四个区域里存放什么数据、由谁管理。

9.2.1 代码区

作用：存放 CPU 执行的机器指令。我们写下的每一个函数体，经过编译后都变成一条条二进制指令，存放在代码区。代码区有两个特点：

  • 共享的：对于频繁被执行的程序，只需要在内存中有一份代码即可，比如同时打开同一个程序的两个窗口，运行的数据有两份，但代码在内存中只有一份；
  • 只读的：把代码区设置为只读，是为了防止程序意外地修改了它的指令。

注意：代码区由操作系统管理，程序员不需要、也不能对代码区进行读写操作。

9.2.2 全局区

作用：存放全局变量、静态变量和常量，全局区的数据在程序结束后由操作系统释放。全局区中常见的成员有：

  • 全局变量：定义在函数外部的变量；
  • 静态变量：用 static 关键字修饰的变量；
  • 字符串常量：用双引号括起来的一串字符，例如 "hello world"；
  • const 修饰的全局变量。

9.2.3 栈区

作用：存放函数的参数值(形参)和局部变量等，由编译器自动分配和释放，==函数执行完后，栈区的数据自动释放==。栈区还有两个特点：

  • 栈区的开辟和释放由编译器自动完成，不需要程序员操心；
  • 栈区空间有限(通常只有几 MB)，不适合存放特别大的数据。

注意：不要返回局部变量的地址！栈区的数据由编译器自动释放，函数执行完后，局部变量所占的内存就被回收了，再拿着返回的地址去访问，得到的就是垃圾值。

9.2.4 堆区

作用：由程序员分配和释放，若程序员不释放，程序结束时由操作系统回收。C++ 中主要利用 new 关键字在堆区开辟内存。

总结：栈区和堆区的核心区别是==栈区由编译器自动管理，堆区由程序员手动管理==。堆区的内存用完要记得释放，否则会造成内存泄漏。

9.3 new 操作符

作用：在堆区开辟内存。C++ 中利用 new 在堆区开辟数据，利用 delete 释放堆区数据。

语法：

  • 开辟单个变量：new 数据类型(初始值);，new 返回的是==该数据类型的指针==；
  • 释放单个变量：delete 指针;；
  • 开辟数组：new 数据类型[元素个数];；
  • 释放数组：delete[] 指针;，释放数组时必须加上方括号。

总结：堆区内存的使用分三步：new 开辟 → 使用 → delete 释放。new 的返回值是该数据类型的指针；释放单个变量用 delete，释放数组时 delete 后面要加方括号。
